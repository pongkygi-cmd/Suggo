Sugo - installable iPhone web app (PWA)

1. Upload this whole folder to any static host (Netlify Drop, GitHub Pages, Cloudflare Pages).
   It must be served over https.
2. Open the https address in SAFARI on your iPhone.
3. Tap Share > Add to Home Screen > Add.
4. Open it from the Home Screen icon. It runs full-screen and works offline.

Privacy: all data stays on the phone (localStorage). No accounts, no network calls, no linked apps.
Open the app from the Home Screen icon once before entering data, because Safari and the
Home Screen app keep separate storage. Use Setup > Copy backup now and then.
